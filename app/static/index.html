Bienvenue ! Tapo Web cherche vos caméras sur le réseau. Choisissez la vôtre ci-dessous, ou ajoutez-la à la main.

Caméras

Compte TP-Link

Le mot de passe de votre compte dans l'appli Tapo. Les caméras le demandent pour lire leur carte SD, il est le même pour toutes les caméras du compte.

Ces identifiants restent sur cette machine (fichier cameras.json, lisible par vous seul). Ils ne sont jamais envoyés ailleurs qu'à vos caméras.

Compte de la caméra

À créer dans l'appli Tapo : la caméra → ⚙ → Paramètres avancés → Compte de la caméra. Il sert au live et à l'orientation.

Compte TP-Link

Le mot de passe de l'appli Tapo, pour la carte SD. Pour que la caméra l'accepte en local, activez « Compatibilité tierce » dans l'appli Tapo : Moi → Tapo Lab → Compatibilité tierce.
